# CubeGame

## Features:

- Voxel terrain generation with Perlin noise
- World is divided into chunks
- Chunk draws geometry with instanced static mesh
- Optimization of invizible cubes
- Dynamic chunk loading in some radius around the player
- Chunk objects pulling
- Cubes mining and highlighting effects

## Inputs:

- Movement - W,A,S,D
- Camera rotation - Mouse
- Jumping - Space
- Mining cubes - Left Mouse Button
- Placing cubes - Right Mouse Button
